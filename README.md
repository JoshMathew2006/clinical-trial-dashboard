I created this small data analytics project in order to learn the basics of data analysis and so that I could gain a fuller understanding of how PANDAS can be used to
clean clinical data, standardize it, and finally analyze the efficacy of the drugs/medicines involved in a clinical study.  This web app takes a csv file as input and 
returns a downloadable csv file that has been cleaned and standardized as output.  Two testable csv input files are available in this repo.
